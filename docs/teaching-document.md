# 教学文档实现契约

新增深模块 `teaching_document` 将内容组织与长正文生成藏在 compose interface 后；结构 JSON 保存块类型、短标题、目的与证据引用，正文通过独立纯文本调用生成并保存。每章必须包含 summary，提示块必须携带受控教学信号和证据；图片使用 figure_id 引用。

`visual_resolver.resolve` 从原视频按语义区间抽帧，分批比较后再次比较优胜候选。可选裁剪必须通过二次视觉确认。缓存包含媒体大小/修改时间、请求、模型、采样参数和版本，失败保留 unresolved。局部候选不依赖 OCR manifest，因此报告直接读图资产。

`document_review.review` 按章节对原始 speech 与 Knowledge Items 审查，并有限次修复文字、补入遗漏块、替换章节教学结构、重选配图。图片经独立 VLM 复审；审查失败的图把问题理由与拒绝时间反馈给 VisualResolver。修订后的教学大纲写入 `teaching-outline.json`，具体结构变化写入 `outline-revisions.json`；最终综合使用修订后的正文与大纲。超过轮次仍有 error 才保留 partial。

每轮审查、每个成功修订和结构修复中新块的生成均以原子 JSON 检查点保存。中断后继续剩余块和复审，完成的修订会恢复到最终文档。审查缓存以章节原文、局部证据、图片内容、模型身份和预算为依赖；独立图片复审以图片内容及附近解释为依赖。

教学文档的计划缓存按章节分开，正文按块缓存。图片使用稳定的逻辑 figure_id，候选资产保持版本化；单张图片变化只使邻近解释和显式 figure_ids 引用块失效。改变章节证据使该章节的初稿、结构计划、正文与审查失效；最终综合随后刷新。完整任务状态也核对输入指纹，不再仅依据 complete 标记复用。报告缓存包含正文、图片、封面和附录摘要，改变 renderer 不调用模型。

HTML 和 LaTeX renderer 共享教学文档。HTML 转义模型文本；LaTeX 转义特殊字符、复制资产并生成同页来源脚注。新版 HTML/PDF 恢复视频元数据、术语表、校正附录和可选完整转录；TeX 也支持术语、校正与转录附录。完整转录优先使用 verified，其次显式输入，最后按现有目录查找。旧报告继续读取旧结构。新增模式不提取或生成公式/源码，不调用 TeX 编译器。

当前局限：请求解析和章节写作仍顺序执行；成本上限为每请求候选数与修订轮次。结构修订作用于既有章节内部，不自动跨章节重划源时间范围。全局大纲重新规划可能合理地改变多个章节；缓存按实际变动的依赖复用，不能保证任意上游编辑只改一个章节。全局场景帧另补一分钟间隔采样，覆盖静态课件与场景预算耗尽后的视频尾部。真实模型整片效果仍需独立评测。
